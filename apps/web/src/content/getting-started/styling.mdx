## Overview

Craft UI design tokens are defined using the modern **OKLCH** color space and integrated with **Tailwind CSS v4** via `@theme inline`. The system provides a neutral foundation designed to be flexible, fully themeable, and easily customized to match any design language.


## Shadcn/UI Compatibility

The token system is engineered to be **100% drop-in compatible with shadcn/ui**. If your project already uses shadcn/ui or you plan to mix and match components, all standard semantic tokens align identically:

## Semantic Extensions

- `--success` & `--success-foreground`: Background and text colors for success/positive outcomes.
- `--warning` & `--warning-foreground`: Background and text colors for warnings, cautions, and pending states.
- `--info` & `--info-foreground`: Background and text colors for informational hints, tips, and guidance.
- `--invert` & `--invert-foreground`: Background and text colors for high-contrast inverted surfaces.
