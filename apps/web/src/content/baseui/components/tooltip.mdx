## Anatomy

#### Components

```tsx
<TooltipProvider>
  <TooltipRoot>
    <TooltipTrigger />
    <TooltipContent />
  </TooltipRoot>
</TooltipProvider>
```

#### Primitives (Base UI)

```tsx
<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger />
    <Tooltip.Portal>
      <Tooltip.Positioner>
        <Tooltip.Popup>
          <Tooltip.Arrow />
          <Tooltip.Viewport />
        </Tooltip.Popup>
      </Tooltip.Positioner>
    </Tooltip.Portal>
  </Tooltip.Root>
</Tooltip.Provider>
```
