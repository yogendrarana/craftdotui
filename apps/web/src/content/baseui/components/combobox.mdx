## Props

#### ComboboxInput

| Prop         | Type        | Description                                              | Default |
| ------------ | ----------- | -------------------------------------------------------- | ------- |
| size?        | "sm"\|"md"\|"lg" | The size of the input                                    | "md"    |
| showClear?   | boolean     | If true, shows a clear button to reset the selection     | false   |
| showTrigger? | boolean     | If true, shows a trigger button to open the dropdown     | false   |
| startAddon?  | ReactNode   | Provide startAddon like search icon to show on the front | null    |
| autoHighlight?| boolean     | If true, highlights the first option on open             | false   |
