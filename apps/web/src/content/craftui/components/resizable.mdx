## Anatomy

#### Usage

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>One</ResizablePanel>
  <ResizableHandle withHandle />
  <ResizablePanel>Two</ResizablePanel>
</ResizablePanelGroup>
```

```tsx
<Resizable.Root orientation="horizontal">
  <Resizable.Panel>One</Resizable.Panel>
  <Resizable.Handle withHandle />
  <Resizable.Panel>Two</Resizable.Panel>
</Resizable.Root>
```

## Demo

#### Vertical

Use `orientation="vertical"` on `<ResizablePanelGroup />` to stack panels vertically.

<ComponentCodePreview name="craftui-particles-resizable-vertical" />

#### With Handle

Pass `withHandle` to `<ResizableHandle />` to render a visible drag grip indicator.

#### Collapsible

Enable `collapsible` on `<ResizablePanel />` and use `usePanelRef()` to imperatively collapse or expand panels.
