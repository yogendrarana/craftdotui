## Anatomy

#### Usage

```tsx
<EmptyRoot>
  <EmptyHeader>
    <EmptyMedia variant="icon" />
    <EmptyTitle />
    <EmptyDescription />
  </EmptyHeader>
  <EmptyContent />
</EmptyRoot>
```

```tsx
<Empty.Root>
  <Empty.Header>
    <Empty.Media variant="icon" />
    <Empty.Title />
    <Empty.Description />
  </Empty.Header>
  <Empty.Content />
</Empty.Root>
```
