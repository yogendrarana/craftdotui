## Anatomy

#### Usage

```tsx
<Carousel>
  <CarouselContent>
    <CarouselItem>Slide 1</CarouselItem>
    <CarouselItem>Slide 2</CarouselItem>
    <CarouselItem>Slide 3</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
  <CarouselDots />
</Carousel>
```

```tsx
<Carousel.Root>
  <Carousel.Content>
    <Carousel.Item>Slide 1</Carousel.Item>
    <Carousel.Item>Slide 2</Carousel.Item>
    <Carousel.Item>Slide 3</Carousel.Item>
  </Carousel.Content>
  <Carousel.Previous />
  <Carousel.Next />
  <Carousel.Dots />
</Carousel.Root>
```

## Demo

#### Sizes

Use `basis-*` utility classes on `<CarouselItem />` to display multiple slides per view.

<ComponentCodePreview name="craftui-particles-carousel-sizes" />

#### Spacing

Customize the gap between slides by applying `-ml-*` on `<CarouselContent />` and a matching `pl-*` on `<CarouselItem />`.

<ComponentCodePreview name="craftui-particles-carousel-spacing" />

#### Orientation

Set `orientation="vertical"` to scroll slides vertically.

<ComponentCodePreview name="craftui-particles-carousel-orientation" />

#### With Dots

Use `<CarouselDots />` to render clickable pagination indicators for the slides.

<ComponentCodePreview name="craftui-particles-carousel-with-dots" />

#### With Counter

Use `setApi` to listen to Embla events and display an active slide counter.

<ComponentCodePreview name="craftui-particles-carousel-with-counter" />
